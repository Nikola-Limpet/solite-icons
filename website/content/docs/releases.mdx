## 0.3.0 candidate, unpublished

The local candidate contains **553 original icons**, including **300 additions** for interface controls, editing, accessibility settings, and application categories. All 253 existing names and drawings are preserved.

It adds `SoliteProvider` for visual defaults, the TypeScript-only `SoliteIconComponent` type, and `nonScalingStroke` on drawing elements. The opt-in `/lazy` entry provides `LazySoliteIcon`; the existing `/dynamic` entry remains eager. The React-free `/metadata` entry provides `iconMetadata`, `isIconName`, `searchIcons`, and a curated `lucideIconMap` migration aid.

Package, metadata, lazy-bundling, browser accessibility, and hydration checks accompany the candidate. Manual VoiceOver and NVDA checks remain separate and are not claimed as completed. See the [accessibility checklist](/accessibility#reproducible-voiceover-and-nvda-checklist).

**npm latest remains 0.2.1.** Use the [local archive workflow](/installation#preview-the-local-030-candidate) to try the candidate. From a clone with root and website dependencies installed, `npm run docs:candidate` builds and installs the archive into the docs app without changing its registry lockfile. `npm run docs:restore` reinstalls the locked published dependency.

The [recorded size benchmark](https://github.com/Nikola-Limpet/solite-icons/blob/main/docs/benchmarks/2026-10-27.md) uses Solite 0.2.1 and its stated comparison versions. It does not measure this candidate.

## 0.2.1

The collection contains **253 icons**, including 24 additions for developer tools, media, sharing, accessibility, learning, and everyday utilities.

Every addition includes named and deep React imports, dynamic names, TypeScript declarations, an SVG file, a sprite symbol, and a catalog entry. The 229 original drawings are unchanged.

```bash
npm install solite-icons@0.2.1
```

[View the GitHub release](https://github.com/Nikola-Limpet/solite-icons/releases/tag/v0.2.1) or [open the npm package](https://www.npmjs.com/package/solite-icons).

## 0.1.0

The first release contains 229 original rounded outline icons extracted from Solite POS, with React components, SVG files, framework-free geometry, TypeScript declarations, and the searchable catalog.

## npm and GitHub Packages

Install `solite-icons` from the public npm registry. The repository's GitHub **Packages** panel belongs to a separate registry and does not list releases published to npm. GitHub **Releases** holds version notes, a source archive, and the attached npm archive.

The normal install command needs no GitHub token or custom registry:

```bash
npm install solite-icons
```

See the repository's [changelog](https://github.com/Nikola-Limpet/solite-icons/blob/main/CHANGELOG.md) for the full version history.
