## Original drawings

The collection started with 229 icons drawn for Solite POS. The 24 additional essentials extend the same 24px grid, rounded outline style, and default stroke. The source geometry is in [`src/definitions/`](https://github.com/Nikola-Limpet/solite-icons/tree/main/src/definitions).

The unpublished 0.3.0 candidate adds 300 original drawings for a total of 553 while preserving those 253 existing drawings. Similar use cases or migration names do not imply copied Lucide geometry or interchangeable artwork.
