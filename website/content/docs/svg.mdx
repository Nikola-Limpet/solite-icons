## Copy a file

Copy an icon from `node_modules/solite-icons/svg/` into your public directory, then use a normal image tag.

Available files depend on the installed package. The published 0.2.1 release has 253 icons; the unpublished local 0.3.0 candidate has 553. Use the [local archive workflow](/installation#preview-the-local-030-candidate) for candidate files. Keep downloads and React previews on the same installed version.

```html
<img src="/icons/shop.svg" width="20" height="20" alt="Shops" />
```

Use `alt=""` when adjacent text already describes the image.

An SVG loaded through `<img>` does not inherit the page's text color. Use inline SVG or the sprite when CSS should control the stroke.

## Import an asset URL

With Vite's standard asset handling:

```tsx
import shopUrl from "solite-icons/svg/shop.svg?url";

<img src={shopUrl} width={20} height={20} alt="Shops" />;
```

TypeScript needs Vite's usual `vite/client` declarations. Other bundlers may return source text or a component instead of a URL. The library does not install an SVG loader for you.

## Use the sprite

Copy `node_modules/solite-icons/sprite.svg` to your public directory. Every symbol ID starts with `solite-`.

```html
<svg width="20" height="20" viewBox="0 0 24 24" aria-hidden="true" style="color: #2563eb">
  <use href="/icons/sprite.svg#solite-shop"></use>
</svg>
```

For an informative SVG, add an accessible label and `role="img"` instead of `aria-hidden`.

## Manifest

`manifest.json` lists all icon names, React component names, SVG paths, categories, and default geometry settings.
