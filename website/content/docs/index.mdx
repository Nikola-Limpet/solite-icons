## Start with one icon

Import a component, set its size, and let it inherit your text color. Named imports support tree shaking, so your bundle includes the icons you use.

```tsx
import { CoffeeIcon } from "solite-icons";

export function CoffeeLabel() {
  return (
    <span className="inline-flex items-center gap-2">
      <CoffeeIcon size={20} />
      Coffee
    </span>
  );
}
```

The package includes React components, standalone SVGs, and TypeScript declarations. No icon font or stylesheet is required. [Read the installation guide](/installation) for npm, pnpm, and Bun.

## Make it yours

These are the actual package components. Adjust the size, color, and stroke, then copy the resulting JSX. The defaults use a **24 × 24 grid**, a **1.75px stroke**, and **rounded caps and joins**.

## Find your way

- [Browse the full collection](/icons) for app controls, commerce, developer tools, media, accessibility, and everyday interfaces.
- [React usage](/react) covers named imports, refs, typed icon slots, and visual defaults.
- [Styling](/styling) explains size, stroke, CSS, Tailwind, and dark mode.
- [Accessibility](/accessibility) helps you label meaningful icons and keep decorative ones quiet.
- [Dynamic and lazy names](/dynamic) explains runtime rendering and metadata search.
- [Migration](/migration) covers name and prop differences when moving from Lucide or the app's Uicons.
- [Plain SVG](/svg) works in HTML, Vue, Svelte, Laravel, and projects without React.

React components support **React 18.2 and 19**. The package includes ESM and CommonJS. React is optional when using only SVG files or geometry data.
