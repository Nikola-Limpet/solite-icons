Solite Icons gives your navigation, buttons, checkout screens, and dashboards one consistent visual language. Every glyph uses a **24 × 24 grid**, **1.75px stroke**, and **rounded caps and joins**.

Import only the icons you use. Control their size and color with React props or CSS. No icon font or stylesheet is required.

## Start with one icon

```bash
npm install solite-icons
```

```tsx
import { ShopIcon } from "solite-icons";

<ShopIcon size={24} className="text-blue-600" />;
```

The package includes React components, standalone SVGs, and TypeScript declarations.

## Requirements

React components support React **18.2 and 19**. SVG files and the data entry work without React. The package includes ESM, CommonJS, and TypeScript declarations.
